================================================================
执行顺序（对应 workflow.sh --all）
================================================================
  Stage 0  → 00_bulk: UO2/MO2/O2 体相优化
      │  [N1] a_calc 与 5.47 A 偏差 < 2%
      ▼
  Stage 1  → 01_surface_generation: 111/110/100 slab
      │  [N2] E_sur(111) ∈ [0.45, 0.60] J/m²
      ▼
  Stage 2  → 02_stoichiometric_MOX: 4 元素 × 4 含量 × 3 晶面
      │  [N3] E_rep 趋势单调
      ▼
  Stage 3  → 03_substoichiometric: O 空位（UO2-x 与 MOX）
      │  [N4] UO2 空位能 ≈ 5.81/5.47/4.98 eV
      ▼
  Stage 4  → 04_hyperstoichiometric: 间隙 O（UO2+x 与 MOX）
      │  [N5] 间隙 O 形成能与空位能对比合理
      ▼
  Stage 5  → 05_subsurface_111: 次表面掺杂方法 B/C（仅 111）
      │  [N6] 方法 A/B/C 替换能差异 < 0.2 eV
      ▼
  Stage 6  → 05_pydefect: 缺陷形成能/电荷态/转变能级
      │  [N7] 转变能级位于带隙内、排序内洽
      ▼
  Stage 7  → 06_analysis + results: 汇总表格/图/自旋/Bader
            [N8] 所有物理量趋势自洽 → 出报告
