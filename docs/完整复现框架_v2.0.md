## 一、文章方法论核心提取

### 1.1 计算参数总结

| 参数 | 设置值 | 说明 |
|------|--------|------|
| VASP版本 | 5.4.1 | PAW方法 |
| 泛函 | GGA-PBE | PBE-Sol不如PBE |
| DFT+U | Ueff=4 eV (U=4.5, J=0.5) | Dudarev方法，5f电子 |
| 截断能 | **650 eV** | 足够大，忽略Pulay应力 |
| k点网格 | **5×5×1** (表面) | Monkhorst-Pack |
| 磁性 | 1k共线AFM | 奇数层spin-up，偶数层spin-down |
| 自旋轨道耦合 | 忽略 | 对表面稳定性影响极小 |
| 真空层 | **18 Å** | |
| 表面尺寸 | **2×2** | |
| 弛豫方式 | ISIF=2 (MOX/亚化学计量比) | 形状体积固定，离子弛豫 |

### 1.2 模型构建方法

- **Slab模型**：6层，24个UO₂单元(U₄O₈×6)，2×2 面内 = 96 原子
- **表面**：(111)、(110)、(100)
- **掺杂方式**：slab两侧对称替换，消除偶极效应；方法 A=表面层、B=2nd+5th、C=3rd+4th
- **化学计量比**：U₂₄₋₂ₙAn₂ₙO₄₈ → U₁₋ᵧAnᵧO₂，y = 0.08/0.17/0.25/0.33
- **O空位**：两侧各移除一个O → O:M=1.92:1
- **间隙O**：两侧八面体间隙(1/2,1/2,1/2)加O → O:M=2.08:1

### 1.3 关键计算公式

- **表面能**：E_sur = (E_slab − N_fu×E_bulk_UO2) / 2
- **替换能**：E_rep = (E_MOX − n_U×E_UO2_fu − n_M×E_MO2_fu) / 2
- **O空位形成能**：E_for = (E_sub + E_O2 − E_sto) / 2
- **间隙O形成能**：E_for(Oi) = (E_hyper − E_sto − E_O2) / 2
- 因子 1/2 来自两侧对称操作；E_O2 为三重态 O2 分子 20 Å 盒子能量

### 1.4 数值基准（分支判断依据）

| 物理量 | 基准值 |
|--------|--------|
| UO2 晶格常数 | 5.47 Å（偏差 <2%）|
| 表面能 E_sur | 111=0.51 / 110=0.91 / 100=1.34 J/m² |
| UO2 O 空位能 | 111=5.81 / 110=5.47 / 100=4.98 eV |
| U(IV) 自旋密度 | ≈2.0 μB |
| DFT+U 带隙 | ≈1.8–2.2 eV（转变能级参考）|

## 三、执行工作流（Stage 0-7）

```
Stage 0 → 00_bulk: UO2/MO2/O2 体相优化
```

## 四、完整操作步骤与代码说明

### 步骤 0：环境准备

```bash
# Python 3.11 + 依赖（已在本环境验证）
pip install numpy ase pymatgen pydefect pyyaml

# 验证 VASP 可用性
which vasp_std mpirun || echo "需在计算节点配置 VASP 5.4.1"
```

### 步骤 1：生成 POTCAR（需本地 VASP 赝势库）

```bash
# 编辑 potcars/make_potcar.sh 中的 POTCAR_DIR 指向 PAW_PBE 库
bash potcars/make_potcar.sh
```

### 步骤 2：运行完整工作流

```bash
# 全量顺序执行（每个 Stage 自动：生成结构 → 写输入 → 跑 VASP → 提示分支判断）
./workflow.sh --all

# 或按阶段/断点续跑
./workflow.sh --stage 0        # 只跑体相
./workflow.sh --resume 3       # 从 Stage 3 继续
./workflow.sh --stage 6 --defect Va_O1   # 只算 O 空位 pydefect
```

### 步骤 3：监控与收敛检查

```bash
./monitor.sh --watch            # 每 60s 刷新进度/失败/资源
./monitor.sh --stage 2          # 只监控 Stage 2
python3 scripts/check_convergence.py . --csv results/conv_summary.csv
```

### 步骤 4：后处理分析

```bash
python3 scripts/analyze_energies.py --out results/energies.csv
python3 scripts/bader_analysis.py --dirs 03_substoichiometric/U1-yMoyO2-x/MOX-8/111/vac_next_to_dopant --run-bader --csv results/bader.csv
```

### 步骤 5：pydefect 缺陷热力学

```bash
python3 05_pydefect/run_pydefect.py setup              # 生成完美超胞+缺陷目录
# 对 05_pydefect/*_q* 目录跑 VASP（各电荷态）
python3 05_pydefect/run_pydefect.py parse               # 解析 calc_results
python3 05_pydefect/run_pydefect.py formation-energy    # 形成能图数据
```

### 步骤 6：SSHP 会话状态迁移

```bash
# 会话开始时（新机器/新会话）：拉取 home 状态
bash scripts/sync-session-state.sh pull
# 查看两端差异
bash scripts/sync-session-state.sh status
# 会话结束时：项目状态推送到 home + 自动备份
bash scripts/sync-session-state.sh push
```

## 五、各 Stage 脚本代码说明

### 5.1 structure_utils.py（核心构建库）

```python
build_uo2_bulk_pymatgen(a)          # UO2 萤石体相（12 原子）
generate_slab(bulk, miller, ...)    # 自动扫描生成 6 层 slab，再扩 2×2
assign_layers(structure, axis=2)    # 按 U z 聚类分层（修正 111 面 O 层）
sort_by_species(structure, order)   # 强制 U-M-O 原子顺序（VASP 要求）
write_structure(structure, file)    # 写 POSCAR 并保持顺序一致
```

### 5.2 vasp_utils.py（输入/解析）

```python
write_incar(dir, system, calc_type, n_ions, magmoms, species_order)
    # calc_type: bulk(ISIF=3) / surface_sto(ISIF=3,纯UO2) / surface_sto+ISIF=2(MOX) / surface_substo
write_kpoints(dir, mesh)            # Monkhorst-Pack
build_magmoms(structure)            # AFM 层序（6层: 4*2 -4*2 4*2 -4*2 4*2 -4*2）
read_energy / read_max_force / is_converged / is_failed   # OUTCAR 解析
```

### 5.3 run_pydefect.py（pydefect 集成）

```python
setup:  构建 2×2×2 完美超胞(96原子) + Va_O/Oi/M_U 多电荷态目录 + INCAR(NELECT调整)
parse:  调用 pydefect_vasp calc_results -d <缺陷目录> <perfect>
formation-energy: E_f = E[def] - E[perfect] + mu_O + q*(E_VBM + eF) 简化版
```

### 5.4 sync-session-state.sh（SSHP）

```bash
status  # 显示各文件两端异同
push    # WS→Home（decision/context/reference）；Home→WS（identity/activation 若更新）
pull    # Home→WS（identity/activation 强制；decision/context 按 mtime）
backup  # 同步前备份到 archives/session-state-backups/<ts>_pre-sync/
```

## 七、SSHP 协议集成说明

本项目采用 **SSHP（Session State Handover Protocol）** 保证跨会话可迁移、可续跑：

- 协议文档：`docs/SSHP_PROTOCOL.md`
- 双向同步：`~/.claude/session-state/` ↔ `<project>/.claude/session-state/`
- 文件角色：identity/activation（Home 权威）、decision-log/context/reference（WS 权威）
- 每次会话结束执行 `push`，新会话开始执行 `pull`，同步前自动备份

当前会话状态摘要（v2.0）：
- 决策 D001-D010 已记录（slab 参数、原子排序、MAGMOM、pydefect 超胞等陷阱）
- 结构级验证全部通过：109 个计算目录、96 原子 slab、MOX/空位/间隙构型
- 待办 P0：实机 VASP 计算、POTCAR 拼接、Stage 0-1 收敛验证
