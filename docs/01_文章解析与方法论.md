# 01 文章解析与方法论提取

> 来源：J.-L. Chen, N. Kaltsoyannis, *DFT + U study of U1-yAnyO2-x (An = Np, Pu, Am and Cm) {111}, {110} and {100} surfaces*, Applied Surface Science 537 (2021) 147972.
> 本章是从 PDF 附件全文解析后提取的**操作方法步骤、分析处理过程与结论总结**，是后续所有复现工作的依据。

## 一、文章研究内容概览

文章用 DFT+U 系统研究了 U1-yAnyO2（An = Np, Pu, Am, Cm）三个低指数表面 (111)/(110)/(100) 的**几何结构、电子结构（自旋密度/氧化态）、替换能、O 空位形成能**，并考察了：

1. 纯 UO2 与 UO2-x 表面（空位形成基准）；
2. 表面掺杂（U0.92An0.08O2，即 MOX-8，每侧替换 1 个表面 U）；
3. 亚化学计量比 U0.92An0.08O1.92（每侧移除 1 个 O，O:M = 1.92:1），区分空位**紧邻/远离** An；
4. 次表面掺杂（方法 A：1st+6th 层；方法 B：2nd+5th 层；方法 C：3rd+4th 层），仅 (111)；
5. 高浓度掺杂 y = 0.08 / 0.17 / 0.25 / 0.33（每侧替换 1/2/3/4 个表面 U），仅 (111)。

同时引入 **U-Zr MOX** 作为氧化还原惰性的基准体系，用于剥离掺杂元素对自旋密度分布的影响。

## 二、计算方法（完整复现参数）

| 参数 | 设置 | 说明 |
|------|------|------|
| 软件 | VASP 5.4.1 | PAW 平面波方法 |
| 泛函 | GGA-PBE | 对比过 PBE-Sol，PBE 对表面性质更优 |
| DFT+U | Ueff = 4 eV（U = 4.5, J = 0.5）| 作用对象为 5f 电子（Dudarev 方法） |
| 截断能 | 650 eV | 足够大，Pulay 应力可忽略 |
| k 点 | Monkhorst-Pack，最小 5×5×1 | 表面布里渊区采样 |
| 磁性 | 1k 共线，净磁矩 = 0 | 整体反铁磁（AFM） |
| 自旋轨道耦合 | 忽略 | 对表面稳定性影响极小（Rak 等） |
| Slab 模型 | 6 层 × 24 个 UO2 单元，2×2 | 表面能随 slab 厚度收敛已验证 |
| 真空层 | 18 Å | 消除层间相互作用 |
| 弛豫 | 纯 UO2：全弛豫；MOX 与亚化学计量比：ISIF=2 | MOX 保持与 UO2 相同的表面形状与体积，离子可动 |
| 磁矩初始化 | 1/3/5 层 spin-up，2/4/6 层 spin-down | 保证整体 AFM |
| 掺杂方式 | slab 两侧对称替换 | 消除偶极效应 |

**体系化学式定义**：
- 化学计量比 MOX：U24-2nAn2nO48，即 U1-yAnyO2，n 为单侧替换数；
- 亚化学计量比：从化学计量比 slab 两侧各移除 1 个 O，O:M = 1.92:1；
- y:1-y = An:U（y = 0.08 时 1 个/侧，0.17 时 2 个/侧，0.25 时 3 个/侧，0.33 时 4 个/侧）。

## 三、关键公式与物理量定义

### 3.1 表面能（eq. 1）

```
E_sur = (E_slab - 6 * E_bulk) / 2
```

- E_slab：弛豫后 UO2 slab 总能，含 6 个 U4O8 式量；
- E_bulk：体相总能，1 个 U4O8 式量；
- 分母 2：slab 上下两个表面。

### 3.2 替换能（eq. 2）

```
E_rep = (E_MOX - (1-y) * E_UO2 - y * E_MO2) / 2
```

- E_MOX / E_UO2 / E_MO2：分别为 MOX、UO2、掺杂元素二氧化物表面的总能；
- E_MO2 表面能量取纯 MO2 体系相同晶面/尺寸的结果（本复现项目自行计算）；
- y:1-y 为 An:U 比值；因子 1/2 来自两侧对称替换。

### 3.3 O 空位形成能（eq. 3）

```
E_for = (E_sub + E_O2 - E_sto) / 2
```

- E_sub / E_sto：弛豫后亚化学计量比 / 化学计量比表面总能；
- E_O2：单个三重态 O2 分子在 20 Å 边长盒子中的总能；
- 因子 1/2 来自两侧各生成 1 个空位。

### 3.4 自旋密度与氧化态判定

- 自旋密度 = α 电子数 − β 电子数（au，即 electrons/bohr³），按原子投影；
- 对正氧化态锕系，多余自旋来自未成对 5f 电子：
  - U(IV) = [Rn]5f² → 自旋密度 ≈ 2.0
  - U(III) = [Rn]5f³ → 自旋密度 ≈ 3.0
- 本项目扩展到过渡金属：Mo(IV) d² ≈ 2.0，Nb(IV) d¹ ≈ 1.0，Zr(IV) d⁰ ≈ 0.0，Ti(IV) d⁰ ≈ 0.0（Ti(IV) 无 d 电子；注意 4d/3d 金属氧化态判定需结合 Bader 电荷交叉验证）。

## 四、操作步骤（原文完整流程）

```
Step 1  构建 UO2 体相（萤石 Fm-3m, a ≈ 5.47 Å）
Step 2  优化体相 → 获得 E_bulk 与晶格常数
Step 3  用 Slab 模型构建 (111)/(110)/(100) 表面（6 层、2×2、18 Å 真空）
Step 4  优化纯 UO2 表面 → 获得 E_slab 与表面能 E_sur（验证收敛）
Step 5  在 slab 两侧对称替换表面 U → U1-yAnyO2（MOX-8）
Step 6  优化 MOX 表面（ISIF=2）→ 替换能 E_rep
Step 7  在 MOX 两侧各移除 1 个 O（紧邻/远离 An）→ U1-yAnyO1.92
Step 8  优化亚化学计量比表面 → O 空位形成能 E_for
Step 9  次表面掺杂（方法 B/C，仅 111）→ 位次效应
Step 10 提高掺杂浓度 y = 0.17/0.25/0.33（仅 111）→ 浓度效应
Step 11 后处理：自旋密度、键长位移、电荷等值面、替换能/空位能趋势
```

## 五、分析处理过程（原文采用的分析手段）

| 分析项目 | 处理手段 | 用途 |
|----------|----------|------|
| 自旋密度 | 逐原子投影 α−β 电子数 | 判定氧化态、电荷转移方向 |
| An-O / U-O 键长位移 | 与纯 MO2/UO2 表面键长对比 | 掺杂引起的几何畸变 |
| 电荷等值面（0.05 e/Å³） | 重叠程度对比 | An 与 O 成键强度、混溶性 |
| 空位邻近原子位移 | 阳离子/氧相对空位位移 | 空位引起的结构弛豫 |
| 替换能 vs 氧化还原电位 | 线性拟合 | 氧化还原活性对替换能的决定作用 |
| 空位形成能分组 | U-Np/U-Pu 与 U-Am/U-Cm 对比 | 5f 壳层半充满（f⁷）效应 |
| 浓度-替换能 | 每 An 替换能 vs y 线性拟合（R² 报告） | 浓度效应：Np 促进、其余抑制 |

## 六、文章关键结果（数值基准）

| 物理量 | (111) | (110) | (100) | 备注 |
|--------|-------|-------|-------|------|
| UO2 表面能 E_sur (J/m²) | 0.51 | 0.91 | 1.34 | 本工作；前期 0.65/1.05/1.33 |
| UO2 O 空位形成能 (eV) | 5.81 | 5.47 | 4.98 | PBE0/PEECM 为 5.92/5.15/4.96 |
| U(IV) 自旋密度 (au) | ≈2.0 | ≈2.0 | ≈2.0 | 纯 UO2 表面 |
| 亚化学计量比表面多余电子 | 1 个定域于表面 U，另 1 个分布于空位 + 邻近 U | | | 空位处有电荷密度 |

**氧化态规律**：
- Np：任何位置/浓度下均为 Np(IV)（自旋密度 ≈ 3.0）；
- Am、Cm：始终 Am(III)/Cm(III)（自旋密度 ≈ 6.0/7.0），电子主要来自单个邻近 U；
- Pu：仅表面且相邻 Pu 未被还原时才出现 Pu(III)；次表面 Pu 均为 Pu(IV)；
- Zr：自旋密度 ≈ 0，无电荷转移（惰性基准）。

**能量规律**：
- 替换能：E_rep 随 (111)→(100) 递减；同一晶面随 Np→Cm 递减；与 An(IV)/(III) 氧化还原电位线性相关；
- O 空位形成能：MOX 低于纯 UO2；空位紧邻 An 比远离 An 更易形成；
- 浓度效应：每 An 替换能线性关系；Np 斜率负（促进进一步替换），Pu/Am/Cm 斜率正（抑制）。

## 七、结论总结（供本项目借鉴）

1. 掺杂元素进入 UO2 表面后，An-O 键被拉长、邻近 U-O 键缩短；浓度升高时位移趋于零；次表面掺杂位移可忽略。
2. 掺杂元素的氧化态由其 (IV)/(III) 氧化还原电位决定，Zr 为无电荷转移基准。
3. 替换能与氧化还原电位强线性相关，是筛选掺杂元素的首要判据。
4. O 空位生成后在空位、邻近 U、掺杂元素间重新分配两个电子；空位形成能主要受电子再分布控制。
5. DFT+U 存在亚稳态问题，须用多种初始磁矩尝试并取最低能量构型（本文指出此前空位能差异可能源于亚稳态）。

## 八、向 Mo/Nb/Zr/Ti 体系的扩展设计（本项目核心）

| 特性 | 锕系 An | Mo/Nb/Zr/Ti |
|------|---------|-------------|
| 价电子 | 5f（DFT+U 作用于 f） | 4d/3d（需评估 d 轨道是否需要 +U） |
| 典型氧化态 | +3/+4 | Mo(+4/+6)、Nb(+5)、Zr(+4)、Ti(+4) |
| 离子半径 | An³⁺ > An⁴⁺ | Zr⁴⁺≈0.72 Å、Ti⁴⁺≈0.61 Å、Nb⁵⁺≈0.64 Å、Mo⁴⁺≈0.65 Å（均小于 U⁴⁺≈0.89 Å） |
| 与 U 半径失配 | 较小 | 较大 → 预期引起更大晶格畸变 |
| 氧化还原活性 | 高（多个价态） | Mo 可变价、Nb/Zr/Ti 较稳定 |
| 预期主导机制 | 氧化还原电位 | 半径失配 + 键合差异 + 电子结构 |

本项目用 Mo/Nb/Zr/Ti 替换原文 An，用 **MO2 体相与 MO2 表面**（M = Mo/Nb/Zr/Ti）作为替换能公式中的参考相（原文用 AnO2 表面），其余流程、公式与判据完全照搬原文，从而可直接对比「d 电子过渡金属」与「f 电子锕系」在 UO2 表面的掺杂行为差异。
