# 04 关键技术指标与筛选标准

> 本章定义用于**评价每个计算是否成功、每个结果是否可信**的关键技术指标（KPI），以及后续筛选/取舍标准。这些指标由 `monitor.sh` 与 `scripts/check_convergence.py` 自动提取。

## 一、收敛性指标（每个 VASP 计算必须满足）

| 指标 | 阈值 | 提取方法 | 不满足时的处理 |
|------|------|----------|---------------|
| 电子步收敛 | EDIFF 达标，OUTCAR 出现 `reached required accuracy` | grep OUTCAR | 提高 EDIFF、换 ALGO=Damped 或增加混合步数 |
| 离子步收敛 | \|F_max\| ≤ EDIFFG 阈值（0.02 eV/Å）| OUTCAR 末尾 TOTAL-FORCE 最大分量 | 继续弛豫 / 检查 ISIF |
| SCF 每离子步迭代数 | ≤ 60（>60 提示收敛慢）| 统计 `Iteration` | 增大 SIGMA、调 ALGO |
| 能量漂移 | 末步 dE < 1 meV | 相邻 free energy 差 | 检查亚稳态 |

**硬性通过条件**：OUTCAR 同时满足 `reached required accuracy` 且 `EDIFFG` 力收敛。

## 三、掺杂体系筛选标准

### 3.1 结构/能量筛选

| 判据 | 通过标准 | 说明 |
|------|----------|------|
| 替换能 E_rep | 与半径失配、氧化还原电位趋势一致 | 首要筛选指标 |
| 键长位移 | 位移 < 0.3 Å 视为正常弛豫 | 过大 → 检查是否发生重构 |
| 表面重构 | 无（位移 > 0.5 Å 标记异常）| 排除或单独研究 |
| 浓度-替换能线性 | R² ≥ 0.85（每 An 替换能）| 反映浓度效应方向 |

### 3.2 电子结构筛选（自旋密度）

| 体系 | 期望自旋密度（au）| 判读 |
|------|------------------|------|
| U(IV) | ≈ 2.0 | 正常 |
| U(III)（空位体系）| ≈ 3.0 | 空位电子定域于 U |
| Zr/Ti(IV) | ≈ 0.0 | d⁰，无电荷转移（基准）|
| Mo(IV) d² | ≈ 2.0 | 需与 Bader 交叉验证 |
| Nb(IV) d¹ | ≈ 1.0 | 同上 |
| 空位处电荷 | 有（≥0.2 e 量级）| 与文章一致 |

**异常判定**：
- 掺杂位自旋密度明显偏离期望（> ±0.5）→ 可能发生氧化态改变或亚稳态，须复算；
- 所有 U 自旋密度同时异常 → 检查 MAGMOM 初始化与 LDAU 数组。

### 3.3 缺陷热力学（pydefect）指标

| 指标 | 标准 | 说明 |
|------|------|------|
| 缺陷形成能 | 与表面 E_for 排序一致 | 内洽性验证 |
| 热力学转变能级 ε(q/q') | 位于带隙内 | 深/浅能级判定 |
| 载流子俘获能 | 正值合理 | 陷阱行为评估 |
| 化学势区间 | μ_O 在富氧/贫氧两极端取值 | 对应 UO2±x 环境 |

## 四、运行状态监控指标（monitor.sh 自动评估）

| 监控项 | 信号源 | 评估标准 |
|--------|--------|----------|
| 作业状态 | OUTCAR 收敛标志 | CONVERGED / RUNNING / FAILED |
| 离子步进度 | Ionic step 计数 | 接近 NSW 且未收敛 → 告警 |
| 总能趋势 | free energy 序列 | 单调下降且趋平 |
| 力收敛 | TOTAL-FORCE 最大分量 | < 0.05 接近，< 0.02 达标 |
| SCF 步数 | Iteration 计数 | > 60 告警 |
| 耗时 | Elapsed time | 超预算告警 |
| 内存 | memory used | 超节点内存告警 |

## 五、数据筛除规则

| 情形 | 处理 |
|------|------|
| 亚稳态（多磁矩结果差 > 0.1 eV）| 取最低能量构型，报告中注明 |
| 明显结构重构（位移 > 0.5 Å）| 标记并单独讨论，不纳入统计 |
| 磁性/自旋收敛异常（MAGMOM 漂移大）| 重算 |
| 参考相（MO2）晶格偏差 > 2% | 换赝势或调 +U 后重算 |
| 能量排序与所有物理量冲突 | 先排查 POTCAR 拼接、原子序顺序、ISIF 选择 |

